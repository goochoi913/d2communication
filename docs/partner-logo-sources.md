# Partner logo sources

These are placeholder logos until each organisation supplies its own files. Every SVG was sanitised:

- Removed: scripts, event handlers, external references, editor metadata, CSS classes and width/height.
- Kept: shapes and colours as in the source.
- Trimmed: viewBox tightened to the artwork.

Each file was checked as a render on white and as a white silhouette on #0a0a0a. Checked 2026-10-18.
